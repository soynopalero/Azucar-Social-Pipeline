🌶️ How to run the event machine

Everything happens in the Telegram bot (@AzucarEventsBot). You do three things: tell it about events, tap Approve, and paste into Facebook. The machine does the rest — Monday, Eventbrite, the website, and all the social posts.

The three commands

  • /new — create an event. Answer the questions; it writes everything to Monday, builds the Eventbrite page, and plans the social campaign.
  • /update — change an existing event. Pick it from the list, then just say what you want in your own words (voice-to-text works): "move it to Aug 29", "price is $20", "new flyers". You can send new flyers and tell it the stories behind them — the posts will use those stories.
  • /status — ask the bot if the machine is healthy. Use it whenever something feels stuck ("I published 5 minutes ago and nothing arrived"). It tells you what's running, what's broken, and what to screenshot for Pedro.
  • /cancel — bail out of whatever's in progress. Nothing is saved. If the bot ever seems stuck or confused, send /cancel and start over.

Flyers: two rules

  • Order doesn't matter — send flyers in any order (albums are fine); the machine spots the main/full-cast flyer and makes it the website image. (In /new, the first photo question asks for the main flyer by itself.)
  • When it asks "any story behind these flyers?" — tell it! "It's Alexa's debut", "Cherry Pop is hosting". Each performer's story gets posted with their flyer.

Messages you'll get, and what they mean

"✅ Created on Monday board" — event saved. The website picks it up automatically.
"🎟️ Eventbrite page is being created…" — wait ~2 min, then a message arrives with the Eventbrite link and the FB kit link.
"🖼 Flyers are syncing…" — new flyers are being attached. You'll get a message when they land.
"📣 Captions ready — N variants" — read them, then tap ✅ Approve (posts get scheduled automatically) or ✏️ Redraft (fresh ones come back). Nothing posts until you approve.
"📅 Queued N posts" — done! The posts go out on their own schedule.
No message when you expected one? Wait 5 minutes (things run in ~2-min cycles). Still nothing → screenshot the last thing you see and send it to Pedro.

Your one manual job: the Facebook event (~1 min)

  1. Open the FB Event Kit (link below) — every event that still needs a Facebook page is listed.
  2. Tap ➕ Open Facebook → Create event. Make sure the host is Out And About (the Page, not yourself).
  3. Go down the numbered COPY buttons: name, dates, times, location, description, ticket link. Save the cover image and upload it.
  4. Publish. Copy the new Facebook event's URL, open the Monday item (link at the bottom of the card), paste it into Facebook Event URL.
  5. The card disappears on the next refresh. (You can also 🗂 Archive a card to tuck it away on your device; past events vanish on their own.)

Good to know

  • Eventbrite pages and Facebook events don't update themselves when you /update an event — the bot reminds you with direct links when it matters.
  • Approving new captions for an event replaces its scheduled posts — anything already posted stays.
  • Only upcoming events can be updated. Past ones are history.
  • Something broken or weird? Screenshot it. Every mystery so far has been solved with one screenshot.
